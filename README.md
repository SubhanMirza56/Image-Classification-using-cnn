# Image-Classification-using-cnn
Built a CNN model for CIFAR-10 image classification, achieving 73% test accuracy.

🧠 CIFAR-10 Image Classification using CNN

This project implements a Convolutional Neural Network (CNN) to classify images from the CIFAR-10 dataset, which contains 60,000 32×32 color images across 10 object categories.

The model is built using TensorFlow/Keras and demonstrates the core concepts of deep learning for computer vision, including convolution layers, pooling, padding, and feature extraction.

🚀 Key Features
CNN model built from scratch
Trained on CIFAR-10 dataset (10 classes)
Image preprocessing and normalization
Use of convolution, pooling, and dense layers
Achieved ~73% test accuracy
Model evaluation and performance analysis
📊 Results
Test Accuracy: 73%
Improved understanding of CNN architecture and hyperparameter tuning
